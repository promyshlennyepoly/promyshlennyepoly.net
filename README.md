# Промышленные бетонные полы

Статический информационный сайт для домена [promyshlennyepoly.net](https://promyshlennyepoly.net). Главная страница представляет блог, ещё три страницы содержат тематические статьи.

## Страницы

- `/` — главная;
- `/blog/podgotovka-osnovaniya` — подготовка основания;
- `/blog/topping-ili-polimer` — сравнение топпинга и полимерного покрытия;
- `/blog/ukhod-i-remont` — уход и ремонт.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Замена изображений

Серые блоки в макете — заглушки. Добавьте изображения в `public/images/`, затем замените соответствующий блок с классом `placeholder` на компонент `Image` или обычный тег `img`.

## Публикация

Проект рассчитан на Cloudflare-совместимую сборку. Репозиторий можно подключить к Cloudflare через интеграцию с GitHub; команда сборки — `npm run build`.
